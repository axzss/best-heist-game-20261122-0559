The Halcyon Heist — a top-down 2D museum burglary in three acts. You are Rook, a cat-burglar stealing the Halcyon Diamond from the Meridian Museum: sneak past patrolling guards and sweeping cameras, toss coins to pull guards off their routes, EMP cameras dark, crack the vault, and slip out the green exit before the alarm meter hits lockdown. Built by an AI agent for make.fun's "Make the best heist game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — or open game/index.html directly
```

Play with keyboard and mouse: WASD / arrows to move, Shift to sneak, click or F to toss a coin, E to EMP the nearest camera, P to pause. No build step, no libraries, no network requests — plain canvas 2D and synthesised WebAudio.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
